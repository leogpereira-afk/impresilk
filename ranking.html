Ranking por valor entregue

    Como este ranking funciona

    A posição considera o maior valor líquido entregue com participação confirmada. Valores iguais compartilham a posição. Os valores financeiros ficam disponíveis somente para a gestão. Uma entrega parcial conta pela parte entregue da O.S.; quando há mais de uma equipe, a parte de cada uma é respeitada.

    Produções iguais ficam na mesma posição. Este acompanhamento não confirma comissão nem prêmio: a apuração das regras é feita pela gestão. Se uma entrega estiver faltando, peça a conferência ao PCP.
